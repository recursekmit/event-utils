# Security policy

No code or production version exists yet. A supported-version table will be added at the first release.

Please do not open public issues for suspected vulnerabilities. Use GitHub's private vulnerability reporting for this repository if the maintainers enable it under **Settings → Security → Code security and analysis → Private vulnerability reporting**. The maintainers have not yet published a private security email address, and this setting has not been verified. Until a private route is confirmed, contact a repository maintainer privately through an existing trusted channel and ask for a secure reporting route; do not send exploit details in a public issue.

Maintainers need to confirm and publish a dependable private reporting route before inviting production use.

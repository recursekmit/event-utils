# event-utils

An open-source idea for a self-hosted hackathon and club-event platform: one installation that runs all of an institution's events, so a new event is configured, not rebuilt.

**Current status:** idea only. This repository holds the [idea and problem statement](docs/CONTEXT.md). There is no code, architecture, or roadmap yet.

# Contributing

Read the [idea and problem statement](docs/CONTEXT.md). The repository currently holds only that idea; there is no code, architecture, or roadmap.

## Issue to PR

1. Open or claim an issue that states the outcome and acceptance criteria.
2. Work on a short-lived branch and make focused changes.
3. Request review and resolve review comments before merge.

Keep credentials out of Git. Report vulnerabilities privately via [SECURITY.md](SECURITY.md). Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

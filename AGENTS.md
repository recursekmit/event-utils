# Agent working rules

- Read [docs/CONTEXT.md](docs/CONTEXT.md) for the idea and problem statement. The repository holds no code, architecture, or roadmap; do not add any unless the task asks for it.
- Change only the assigned scope and preserve unrelated edits.
- At handoff, record branch, base commit, completed and uncommitted work, blockers, and next concrete action in the issue or PR. Do not append to a global status log.
